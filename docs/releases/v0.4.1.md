# Release v0.4.1 — README links on crates.io

**Date:** 2026-10-04  
**Tag:** [`v0.4.1`](https://github.com/AxialDB/ce-stream/releases/tag/v0.4.1)

## Summary

Docs-only patch. The code, CLI behaviour, and JSON and Avro output are the same as [v0.4.0](https://github.com/AxialDB/ce-stream/releases/tag/v0.4.0). Feature notes are in the [v0.4.0 release notes](https://github.com/AxialDB/ce-stream/blob/main/docs/releases/v0.4.0.md).

## Fixed

crates.io resolves relative README links against each crate's folder. The crates share the repository-root README, so every doc link on the 0.4.0 crate pages returned 404. The README now uses absolute GitHub links.
