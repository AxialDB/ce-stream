# Release v0.3.0 — live include-list updates

**Date:** 2026-08-17  
**Tag:** [`v0.3.0`](https://github.com/AxialDB/ce-stream/releases/tag/v0.3.0)  
**Issue:** Closes [#3](https://github.com/AxialDB/ce-stream/issues/3) (update `include_tables` on a live capture session)

## Summary

Embedders can add or remove `database.table` entries on a running `MysqlBinlogSource` without ending the binlog dump thread. The new list is snapshotted at the **next GTID** (start of the next transaction). The current envelope is never split.

## Upgrade notes

### Breaking (struct literals)

`MysqlBinlogSource` gained `include: IncludeList`. Add:

```rust
include: Default::default(),
```

Capture start still copies `config.include_tables` if the handle was never mutated.

### Live updates

```rust
let handle = source.include_handle();
// run() / run_transactions() already in flight on another task:
handle.insert(TableRef::new("demo", "items"));
handle.remove(&TableRef::new("demo", "orders"));
```

- **When it applies:** next GTID. Best-effort; no ack.
- **Empty commits:** fully filtered transactions are still delivered so the GTID watermark advances (same as v0.2.0).
- **Empty list at start:** still means all tables. After start, `remove` of the last table or `replace([])` means no row events.
- **DDL:** Query events are not filtered by the include list.

`delivery_unit` and commit-boundary checkpointing are unchanged.

## Install

### From Git tag (recommended until crates.io)

```bash
cargo install --git https://github.com/AxialDB/ce-stream --locked --tag v0.3.0 ce-stream-cli
```

GitHub Release assets are built in CI (**Linux** `ubuntu-latest` and **Windows** `windows-latest`, equal first-class targets). Verify `SHA256SUMS`.
