# Release v0.4.2 — Mongo server-side include filter

**Date:** 2026-10-09
**Tag:** [`v0.4.2`](https://github.com/AxialDB/ce-stream/releases/tag/v0.4.2)

## Summary

Fixes [#9](https://github.com/AxialDB/ce-stream/issues/9). The Mongo source sends a finite include list to the server as a `$match`. MySQL capture and its output are unchanged.

## Fixed

- With `full_document = "required"`, an update or replace in any collection of the database without post-images ended the stream, also when the collection was not in `include_tables`. A restart from the checkpoint failed on the same event. The server now leaves the writes of collections that are not listed out before it looks for their post-images.
- Every write of the database was sent to the client and dropped there. A bulk load into a collection that was not listed delayed the listed ones. Measured with `mongosh` on MongoDB 8.0.32 and 9.0.2: 14.4 s to get past 100,000 such inserts without the filter, 0.4 s with it.

## What changes for an embedder

- **A collection added to a running capture.** `IncludeList::insert` and `replace` no longer take effect at the next transaction. The source opens its stream again, at the last position it read, with the wider filter. Until then the server still leaves the new collection's changes out. `IncludeList::in_effect_allows("db.coll")` is true once they are delivered. Copy the collection after that, not before.
- **Commits without events.** Writes to collections that are not listed used to arrive as commits with no events, one per write. They no longer arrive. An empty batch whose position has moved is delivered as one commit with no events, so the checkpoint still passes them.
- **`drop` and `rename` of a collection that is not listed** are no longer seen. They only advanced the resume token before.
- **An empty `include_tables`** means every table, as before, and keeps the unfiltered stream. Every collection of the database then needs post-images under `full_document = "required"`.

## Added

- `ce_stream_core::include::IncludeList::{set_in_effect, in_effect, in_effect_allows}`.
- `ce_stream_mongo::ClusterTime::of_resume_token`.

## Tests

Unit tests run in CI. The live test is `crates/ce-stream-mongo/tests/server_filter_live.rs`; it needs a MongoDB 8.0+ replica set and is not part of CI:

```bash
CE_STREAM_MONGO_URI="mongodb://127.0.0.1:27017/?replicaSet=rs0" \
  cargo test -p ce-stream-mongo --test server_filter_live -- --ignored --test-threads=1
```
