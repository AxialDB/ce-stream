## Problem summary

ce-stream reads MySQL 9.x binlogs only. Embedders that keep derived state from MongoDB need Kafka plus a connector, or their own oplog tailer (not possible on Atlas). `ce-stream-core` is also MySQL-shaped: `CommittedTransaction` carries `gtid` / `gtid_set_after`, `DdlStatement` is SQL text, and `IncludeList` lives in `ce-stream-mysql`.

## Behavior

Core (MySQL output unchanged):

- `CommittedTransaction` gains `adapter`, `position`, `position_after`. MySQL fills them from the GTID and the executed set; `gtid` / `gtid_set_after` stay and are empty for non-MySQL sources.
- Typed control event for collection or table lifecycle (dropped, renamed, invalidated). MySQL keeps `DdlStatement`.
- `IncludeList` moves to `ce-stream-core`; `ce-stream-mysql` re-exports it for one release.

`ce-stream-mongo`:

- MongoDB 8.0+ replica set (one node is enough). Standalone is refused at connect.
- One stream per source database, filtered to the include list; live include updates filter client-side.
- `fullDocument: "required"` (post-images) by default; `"updateLookup"` opt-out. Pre-images never requested.
- insert / update / replace / delete map to `ChangeOp`. drop / rename / dropDatabase / invalidate emit the control event and end capture.
- Transactions: consecutive events with the same `(lsid, txnNumber)` are one commit. A group closes on the next different transaction, or when an empty batch advances `postBatchResumeToken` past it.
- Checkpoint payload: `resume_token`, `cluster_time`, `seed_cluster_time`. `ChangeStreamHistoryLost` is a distinct error.
- Seed helper: cluster time `T`, majority-read scan, stream from `T`.
- Connect gates: replica set, 8.0+, `find` + `changeStream`, post-images in `required` mode, oplog window when `clusterMonitor` is granted.
- Explicit BSON to JSON for `ObjectId`, `Decimal128`, `Date`, `Binary`, 64-bit integers.
- CLI `source.adapter = "mongo"`.

## Non-goals (this issue)

- Sharded clusters (`mongos`)
- MongoDB older than 8.0
- Live MongoDB tests in CI
- Avro `committed-transaction-v1` changes

## Tests

CI: unit tests for event mapping, transaction grouping, BSON conversion, and MySQL position fields (`cargo test -p ce-stream-core -p ce-stream-mysql -p ce-stream-mongo`).

Lab (ignored by default, `mongo:8.0.32` one-node replica set): insert, update, replace, delete, multi-document transaction, resume after restart, history lost, drop and rename, seed overlap with concurrent writes. Both `required` and `update_lookup`. One `required` pass on `mongo:9.0.2` before release.
